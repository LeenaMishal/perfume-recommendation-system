# Perfume Recommendation System

A machine learning-based perfume recommendation system that predicts suitable perfume scents based on user preferences such as gender, age, occasion, weather, and perfume strength.

## Features
- Personalized perfume recommendations
- Interactive Streamlit GUI
- Machine learning prediction models
- Probability-based recommendations
- User-friendly interface

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Machine Learning Models
- Decision Tree
- Random Forest

## Project Files
- `app.py` → Main Streamlit application
- `perfume_model.pkl` → Trained machine learning model
- `encoders.pkl` → Encoded categorical values
- `scaler.pkl` → Feature scaling model
- `clean_perfume_data.csv` → Dataset used for training
- `README.md` → Project documentation

## Installation
```bash
pip install pandas numpy matplotlib scikit-learn streamlit
```

## How to Run
```bash
streamlit run app.py
```

## Project Goal
The goal of this project is to demonstrate how machine learning can be used to build personalized recommendation systems with practical real-world applications.
